# Security

## Who can act

Local handoff previews run without desktop access. On macOS the public CLI, MCP tool and installed `jev-run` share a supervisor. Input requires explicit act mode, an expected foreground, and consent from `jev-brain consent` in an interactive terminal. Revoke consent by removing `~/.config/jev-brain/consent.json`.

Before starting an executor, including for `--arm`, the parent reads macOS accessibility (AX) metadata in its own process. It binds the app PID to its bundle identifier and reads the front window, document URL and focused element’s role, subrole, title, description and placeholder. For a named control the parent resolves its exact title or description in the same foreground and checks its metadata before launch. Transport errors, unreadable values, a missing role, window title or identity, and focus changes cause refusal. Optional attributes may be absent when AX explicitly reports them as unsupported or empty.

Only TextEdit, Notes, Finder and Calendar are eligible native apps. A missing or mismatched browser URL fails the expectation check. Even an exact HTTP(S) URL leads to refusal because this release has no trusted browser-origin approval mechanism. This applies to every browser-backed step, including management consoles at regional or private hostnames.

The sensitive-surface classifier normalizes compatibility characters and case, checks known clients and sensitive terms, and refuses residual non-ASCII text, hidden control characters and unresolved URL encodings. Ordinary localized interfaces can therefore be refused. A private document with innocuous metadata can still look ordinary. Never pass credentials or private communications. Arguments can be visible to other processes under your account.

The adapter independently resolves the control and rechecks focus at input time. A press requires a unique exact title or description among elements exposed through the focused window’s AX children. The search retains distinct references at identical coordinates and counts offscreen matches. A failed read, a search over 512 elements, a missing press action, or a centre hit-test that reaches another element stops the step. A write requires an empty focused field. After the final identity check the adapter reads the field again, refuses a changed or unreadable value, and reads back any write. Pixel-only controls and content omitted by the app’s accessibility provider cannot be verified. AX has separate read and write operations, so concurrent edits can still occur between them. A timeout, interruption or lost acknowledgement can follow a mutation. Inspect the app before retrying.

## Local files and executors

Act attempts require a confirmed initial append and filesystem sync before observation or launch. The initial and final records contain a UTC timestamp, random call ID, combined argument length, a known bundle ID when verified, and a fixed outcome code. The program keeps requests, control labels, literal text, window titles, URLs and backend output out of its files. The command returns results to its caller, which may retain them. If the final append fails or exceeds the deadline, the caller receives `audit indeterminate`, the preceding `step_outcome` and its step count. Storage may finish an outstanding append after the response. A crash or storage failure can leave a call with only its initial record. POSIX consent and audit files must be user-owned, single-link regular files with no group or other permissions. Newly created files use mode 0600. The same account can edit its own log and consent file.

The supervisor sets one 30-second monotonic deadline before validation. It bounds waiting for audit storage and native reads inside the parent. Up to four worker threads can hold outstanding operations if the OS stalls. Those threads handle preflight or audit work only. The supervisor alone can launch the executor, and the initial record must finish within budget. The bundled Python backend runs with `-I` in the installed environment, excluding the working directory, user site and `PYTHONPATH` from helper discovery. Install both packages in the same trusted virtual environment. A trusted editable installation includes its source checkout.

The supervisor caps the executor reply at 64 KiB and closes pipes on termination. The four input strings are limited to 4,096 characters each. MCP reads newline-delimited frames in bounded chunks with a 2,000,000-byte limit and ASCII-escapes response JSON. Executor-backed modes require macOS. Windows and Linux support the local preview.

Only use a trusted `jev-run` on the host’s `PATH`. A replacement executable has the host’s permissions, controls its own artifacts, and must enforce the window guard at input time. The included adapter uses local accessibility elements and stores no screen images. Upstream’s full classifier loop has a different data flow, sends state to its configured providers, and writes its own run folder. [Upstream documentation](https://github.com/awlevin/typesafe-computer-use)

## Config and mock server

`jev-brain install` reports the config path and proposed action. With `--yes` it adds a missing server under the current home. Existing jev-brain and systemone entries retain their settings. The installer checks server entries, MCP policy fields and project or profile restrictions. A relevant or ambiguous policy requires a manual edit. Ordinary arguments and environment values on unrelated servers are preserved. A new TOML table must reparse to the expected key path and preserve the rest of the parsed document. Incompatible layouts require a manual edit.

Keep the mock HTTP service on its default loopback address. Remote binding requires `--allow-remote`. The service offers health and fixed closed-question answers. Desktop input is available through the CLI and local stdio MCP. Treat question text and responses as untrusted data. Keep secrets out of mock requests. HTTP request bodies are excluded from server logs.
