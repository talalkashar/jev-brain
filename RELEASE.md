# SystemOne (jev-brain)

Preview an agent's proposed desktop handoff from the terminal. The CLI returns a JSON plan or refuses a target or request matching a sensitive category. For integration tests, the local HTTP mock returns fixed answers to closed questions. Its `health` and `decide` tools are also available over stdio MCP.

The public GitHub release is [SystemOne 0.1.0](https://github.com/talalkashar/jev-brain/releases/tag/v0.1.0). The CLI requires Python 3.11 or newer and has no runtime dependencies. Try the [quickstart, captured output and examples](https://github.com/talalkashar/jev-brain#readme).
